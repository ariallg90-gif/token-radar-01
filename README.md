A token launch radar: it reads a sealed snapshot of 758 DefiLlama protocols, ranks all 226 rankable pre-token protocols by an implied value computed from TVL, seven-day growth, age, chain breadth and recency (model radar-2), and hands in a static dashboard with a sortable, filterable board, a detail view for every protocol and a seven-step farm plan with costs and times for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
